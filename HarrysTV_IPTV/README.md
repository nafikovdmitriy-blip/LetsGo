# Harry's TV (Fire TV Stick / Android TV Client)

A fully rebranded, modern UI IPTV client tailored for **Harry's TV**:
- **App Name & Package:** Rebranded to `Harry's TV` (`com.harrystv.iptv`).
- **Modern Cinematic UI Theme:** Deep obsidian background (`#07090E`), indigo/violet glowing focus rings (`#818CF8`), and smooth card corners optimized for Fire TV Stick D-Pad remote navigation.
- **Dual Login Modes:** Xtream Codes API (`player_api.php`) and direct M3U / M3U8 Playlist URLs.
- **Full Features:** XMLTV EPG Guide Timeline, Series Season & Episode viewer, Favorites system, and live OSD playback.
